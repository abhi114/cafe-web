# Noir Café

A dark, editorial café concept website with a GSAP logo reveal, scroll animations, responsive navigation, animated page transitions, and locally stored café photography.

## Open locally

Open `index.html` in a browser. For the most consistent preview, run a local server from this folder:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Edit

- `index.html` — page sections and copy
- `styles.css` — layout, typography, colors, and responsive design
- `script.js` — mobile menu and GSAP motion
- `assets/` — local images and GSAP libraries
- `menu/` — four animated menu story pages and their shared styles/scripts

The homepage menu links to dedicated stories for Espresso, Slow Brew, Velvet Latte, and Something Sweet. The new Ritual section extends the homepage narrative between the menu and the café space.

This is a design concept. Replace the sample copy, menu, and invitation with the café’s real details before launch. Photography is sourced from [Unsplash](https://unsplash.com); typography loads from Google Fonts.
